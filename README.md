# MPU6050 · ESP32 姿态解算

ESP32-WROOM-32 通过 I2C（SCL/SDA）读取 MPU6050，在板端完成 Mahony 姿态解算，
**每次上电以当前姿态为 0 初始位置**，通过串口输出四元数与欧拉角，
由浏览器 3D 界面实时显示，也支持无硬件时的姿态模拟。

## 项目文件

| 文件 | 说明 |
| --- | --- |
| `MPU6050_Attitude.ino` | ESP32 固件（Arduino 环境，仅用内置 Wire 库，无需第三方库） |
| `姿态解算可视化.html` | 前端 3D 界面（Three.js，串口实时 + 模拟模式） |
| `three.min.js` / `OrbitControls.js` | Three.js r128 本地文件（页面优先加载本地，可离线使用；缺失时自动回退多个 CDN） |
| `启动本地服务器.bat` | 双击启动本地 HTTP 服务器（启用 Web Serial 必需） |

## 硬件接线

| MPU6050 | ESP32-WROOM-32 |
| --- | --- |
| VCC | 3V3 |
| GND | GND |
| SCL | GPIO22 |
| SDA | GPIO21 |
| AD0 | GND（I2C 地址 0x68） |
| XDA / XCL / INT | 悬空 |

> 若你的 MPU6050 模块为带电平转换的 5V 版本，VCC 可接 5V；否则一律接 3V3。

## 固件烧录（Arduino IDE）

1. 首选项 → 附加开发板管理器网址：`https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
2. 开发板管理器安装 `esp32 by Espressif Systems`
3. 开发板选择 `ESP32 Dev Module`（或你的板型）
4. 打开并上传 `MPU6050_Attitude.ino`
5. 串口监视器（115200）可看到 JSON 数据流

**上电后保持模块静止约 3 秒**：程序自动校准陀螺仪零偏，
并把“上电瞬间的姿态”设为 0°。

## 前端使用

1. 双击 `启动本地服务器.bat`（等价于在项目目录执行 `python -m http.server 8080`）
2. 用桌面版 **Chrome / Edge** 打开 `http://localhost:8080`
3. 点击「连接串口」→ 选择 ESP32 所在端口（波特率 115200）
4. 无硬件时切到「模拟」模式：拖动模型、滑条或开启自动演示

> Web Serial 要求安全上下文：必须通过 `http://localhost` 访问，直接双击打开 `file://` 无法连接串口。

## 姿态解算说明

- **上电归零**：以上电时加速度计测得的重力方向建立参考四元数，之后所有输出都是相对该参考的旋转，因此上电姿态恒为 0°
- **滤波**：Mahony 互补滤波（Kp≈0.5，Ki≈0.01），陀螺仪短时积分 + 加速度计重力参考持续校正
- **输出**：四元数 `q0~q3` 与欧拉角 `roll / pitch / yaw`（度，相对参考姿态），串口每行一条 JSON，约 100 Hz
- **重新归零**：前端「重新归零」按钮即可把当前姿态设为 0；固件也支持串口发送字符 `R` 触发重新归零

## 参数调节（MPU6050_Attitude.ino）

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `TWO_KP` | 1.0 | 滤波响应速度，越大跟踪越快，但更易受加速度计噪声影响 |
| `TWO_KI` | 0.02 | 抑制倾斜状态下横滚/俯仰漂移 |
| `LOOP_HZ` | 100 | 解算与串口输出频率 |
| `GYRO_FS` / `ACC_FS` | 2000 / 2 | 传感器量程，与寄存器配置保持一致 |

## 已知限制

- 未使用磁力计，**yaw 无法被重力校正，会随时间缓慢漂移**；
  需要长时间稳定航向请改用带磁力计的模块（如 MPU9250 / ICM-20948）或增加视觉/地磁参考。
- 若模型旋转方向与实物相反，在前端勾选对应「轴反向」即可校正。

## 常见问题

- `MPU6050 not found`：检查 SCL/SDA 是否接反、AD0 是否接 GND、VCC 是否为 3.3V
- 串口连不上：确认端口未被串口监视器占用、页面经 http://localhost 打开、浏览器为 Chrome/Edge 桌面版
- 读数跳动：确认上电 3 秒校准期间模块保持静止
